# 客服规范

## 回答原则

- 基于企业规则和实时业务数据回答，不得自行创造企业规则。
- 实时业务事实以业务系统查询结果为准，不能仅凭历史聊天记录判断。
- 无法可靠判断时，必须转人工客服。

## 订单消歧

当用户问题对应多个候选订单时：

- 不要猜测用户指哪一个订单。
- 应展示结构化订单选项让用户选择。
- 用户选择后再继续处理。

## 多订单对话

- 当前讨论订单记为 active_order_id。
- 历史出现过的订单仍保留在上下文中。
- 用户重新提到其他商品时，应重新定位对应订单。

## 禁止操作（第一版）

以下操作 Agent 不得自动执行，需转人工：

- 修改收货地址
- 直接退款
- 取消订单
- 修改商品规格
- 换货
- 任何资金相关操作

## 转人工时机

- 用户明确要求人工
- 物流异常需核实
- 争议处理
- 超过承诺发货时间且用户情绪升级
- 系统无法给出可靠答案
